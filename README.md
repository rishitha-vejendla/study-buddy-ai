📚 Study Buddy AI

🚀 Overview

Study Buddy AI is a simple AI-powered study assistant designed to help students understand concepts, generate notes, and practice questions easily.

✨ Features

- 📖 Explain study topics in simple language
- 📝 Generate notes for quick revision
- ❓ Answer student questions
- 🎯 Helps in exam preparation
